# 归档_支线v0.3 · 支线 PRD 历史文档

本目录存放**支线（笛语支线系统架构 PRD）**的历史版本，供追溯与复现使用。

## 与 `归档_v1.0/`、`归档_v1.1/` 的区别

`归档_v1.0/` 与 `归档_v1.1/` 存放的是**主线产品真源**的历史版本，其归档动作受
`governance/baseline/founder_pinned_baseline.v0.1.yaml` 管辖，每份都有
`archived_by: <Founder 裁决 ID>` 与钉死的 sha256。

本目录**不属于**该治理链路：支线 PRD 从来不是产品真源，主线唯一活基线仍为
`笛语跨品牌服装搭配专家内核_PRD与执行里程碑_v1.2.docx`。本目录的归档不改变任何主线状态位，
也未触碰「在 v1.2 生效前归档 v1.1」这条红线。

## 为什么把 v0.3.1 纳入版本控制

`笛语支线系统架构PRD_v0.3.2.docx` 是在 v0.3.1 的 OOXML 包上做外科编辑得到的——
样式、编号、媒体、页眉页脚全部原样继承。把 v0.3.1 留在仓库里，v0.3.2 的构建才是可复现、可核对的；
否则「v0.3.2 完整替代 v0.3.1」这句话在仓库内无法被验证。

## 边界

- 历史版本仅供追溯，**不得**作为第二套真源、第二套测试真源或运行时依赖。
- 被采纳的历史语义必须在 v0.3.2 中重新表达；正式合同中不得写「详细设计见历史 v0.3」。
- 支线当前候选为 `笛语支线系统架构PRD_v0.3.2.docx`，状态 `FOUNDER_REVIEW_CANDIDATE`，**未签署、未生效**。
